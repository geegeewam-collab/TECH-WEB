# Supplied artwork used by this website

Source archive: `Black and Grey 3D Shapes Tech Company Presentation (1)(1).zip`

The following two source images are used as website artwork. Their contents were copied without editing or generating replacements:

- `1.png` → `site/assets/backgrounds/1.png` (1920 × 1080)

The website uses CSS background positioning, scaling and dark overlays around these supplied images. The images themselves are retained as original PNGs.


The standalone logo files in `site/assets/brand/` are vector brand assets created for GEEGEE TECH; they are not additional background photography or decorative artwork.

## Premium redesign update

`site/assets/shapes/*.webp` are text-free crops cut from the supplied presentation slides (1, 2, 3, 10, 11 and 12) with the black background converted to transparency. No new artwork was generated.

Fonts are self-hosted in `site/assets/fonts/`: Unbounded (headlines) and Inter Tight (text), both SIL Open Font License, via the Fontsource npm packages.

All premium styling lives in `site/assets/css/premium.css`, loaded after `styles.css`. Delete that one link to go back to the previous look.
